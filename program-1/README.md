
[Purpose]

> parse entire http json file exported from caido to find specified keywords
in various contexts and return it with a word radius specified in the
search config file.


[Features]

- hostname or all
- keyword search
- word radius
- request or response data

[Info]

> Place your json file in the json-file directory
> Configure the search parameters in the search_config/search.json file.
> Do your stuff
